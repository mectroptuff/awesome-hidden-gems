> A self-updating feed of great open-source projects that the community is genuinely excited about — no manual curation required.

A bot checks [Hacker News Show HN](https://news.ycombinator.com/show) every day, picks out the open-source projects people actually upvoted and discussed, and commits new finds straight into this README automatically. Nobody has to lift a finger for the list to stay fresh — that's the whole point. Star the repo to keep the feed on your radar.

## CLI & Terminal

- [harlequin](https://github.com/tconbeer/harlequin) - A SQL IDE for your terminal, with a polished TUI that supports DuckDB, SQLite, PostgreSQL, and more.
- [posting](https://github.com/darrenburns/posting) - A modern, keyboard-first HTTP client that lives entirely in your terminal — think Postman, but fast and scriptable.
- [sttr](https://github.com/abhimanyu003/sttr) - A tiny CLI for everyday string transformations (base64, hashes, case conversion, JSON formatting) with a slick interactive mode.
- [atuin](https://github.com/atuinsh/atuin) - Replaces your shell history with a SQLite-backed, searchable, syncable history that actually understands context.

## Self-Hosting & Infrastructure

- [zrok](https://github.com/openziti/zrok) - A self-hostable alternative to ngrok for secure sharing of local resources, built on OpenZiti's zero-trust networking.
- [ntfy](https://github.com/binwiederhier/ntfy) - Send push notifications to your phone or desktop via a simple PUT/POST request, self-hosted or hosted.
- [netbird](https://github.com/netbirdio/netbird) - A WireGuard-based mesh VPN that connects all your devices into one secure private network with almost no configuration.

## Data & Backend

- [griffe](https://github.com/mkdocstrings/griffe) - A Python static analysis library that extracts API signatures and docstrings — the engine quietly powering great auto-generated docs.
- [pagefind](https://github.com/CloudCannon/pagefind) - A static search library that indexes your site at build time, needs zero backend, and stays tiny even on huge sites.
- [partykit](https://github.com/partykit/partykit) - A platform for adding real-time, multiplayer features (presence, live cursors, sync) to any web app without standing up your own infra.

## Developer Experience & Productivity

- [devtoys](https://github.com/DevToys-app/DevToys) - A Swiss Army knife of everyday dev utilities (converters, formatters, generators) in one offline desktop app.
- [briefer](https://github.com/briefercloud/briefer) - An open-source notebook that blends SQL, Python, and no-code visualizations for teams, not just solo data scientists.
- [wasp](https://github.com/wasp-lang/wasp) - A config language + compiler that scaffolds a full-stack React/Node/Prisma app from a single declarative file.
- [devpod](https://github.com/loft-sh/devpod) - Codespaces-style, provider-agnostic dev environments that run on your own cloud, laptop, or Kubernetes cluster.

## AI & Automation

- [activepieces](https://github.com/activepieces/activepieces) - An open-source, self-hostable automation platform (Zapier alternative) with a fast-growing library of AI-native pieces and MCP support.
- [openhands](https://github.com/All-Hands-AI/OpenHands) - An open platform for AI software-development agents that can actually write code, run commands, and browse the web to finish a task.
